# NETU ALAZ Autonomous

## Setup

1. **Docker'ı kur**: Sisteminize Docker'ı indirip kurun
   - https://www.docker.com/get-started/

2. **Repoyu klonla**:
   ```bash
   git clone https://github.com/efekaanguler/alaz.git
   cd alaz
   ```

3. **Başlatma scriptini çalıştır**:
   ```bash
   ./repo_init.sh
   ```
## Running

```bash
./dev_run.sh
```
